# Wi-Fi 파동 시뮬레이션

집 평면도 형태의 2D 지도에서 공유기와 관찰점을 움직이고, 문을 여닫으며 Wi-Fi 파동의 **모형상** 분포를 비교하는 실험 도구입니다.

## 실행

`index.html`을 브라우저에서 엽니다. 외부 라이브러리나 서버가 필요하지 않습니다.

## 조작

- 공유기와 관찰점은 끌어서 이동하고, 문은 눌러 여닫습니다.
- 빈 곳을 끌면 지도가 움직입니다.
- 마우스 휠 또는 두 손가락 벌리기로 확대·축소합니다.
- 작은 화면에서는 ‘결과 보기’와 ‘지도 보기’로 화면 사이를 이동합니다.
- 모형은 **반사 제외 → 완전 반사·투과 없음 → 반사·투과** 순서로 선택합니다.

## 해석

1m에서 측정한 RSSI를 기준값으로 사용합니다. 빨강·파랑 파동은 실제 Wi-Fi 파장이나 간섭무늬가 아닙니다. ‘순간 파동 세기’는 관찰용 격자의 순간값을 dBm 눈금에 맞춘 수치이며 실제 휴대폰의 순간 RSSI와 다릅니다. 완전 반사 모드는 모든 구조물을 차단하는 가상 비교 조건입니다.

건축 재료와 실내 전파의 이론적 참고 자료: [ITU-R P.2040](https://www.itu.int/rec/R-REC-P.2040), [ITU-R P.1238](https://www.itu.int/rec/R-REC-P.1238).
